# 📦 Base Frontend Shell
> **Purpose:** The standard clean-slate implementation for generic full-stack features.

## 🛠️ Tech Stack
- **Framework:** Vue 3 (Composition API)
- **State Management:** Pinia
- **Styling:** Tailwind CSS

## 🔧 Features
- **Integrated Auth:** Pre-configured with login and registration views.
- **Standard Layout:** A versatile navbar and container system suitable for most CRUD applications.
