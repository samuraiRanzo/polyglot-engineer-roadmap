# ⌨️ Terminal Frontend Shell
> **Purpose:** A retro-CLI aesthetic for system-level and cybersecurity challenges.

## 🎨 Theme & UI
- **Visuals:** CRT Scanline overlay and Matrix-green color palette (`#00ff41`).
- **Font:** Monospaced `Courier New` for a classic terminal feel.

## 🔧 Configuration
- **Prompt Logic:** Simulated CLI prompt (`ranzo@roadmap:~$ `).
- **Styles:** Custom `terminal.css` manages all low-level CRT effects.
