# 📊 Dashboard Frontend Shell
> **Purpose:** Tailored for data-rich administrative systems and real-time analytics.

## 🎨 Theme & UI
- **Layout:** Fixed sidebar with top-bar navigation.
- **Status Monitoring:** Integrated `ServiceStatus.vue` component with a 30-second heartbeat to the backend.

## 🔧 Components
- **Server Status:** Provides live visual feedback (Online/Offline) of the Django bridge.
- **Data Views:** Optimized for displaying tables and stakeholder information.
